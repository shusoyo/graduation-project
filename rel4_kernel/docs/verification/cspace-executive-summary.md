# reL4 CSpace 验证项目：极简执行总览 (Executive Summary)

> **最后更新：2026-04-30** | **项目状态：工程闭环已完成，聚焦论文防守阶段**

## 1. 核心大图 (我们在干什么)
本项目旨在使用 Rust/Verus 对 reL4 (seL4 的 Rust 重写版) 的 **CSpace（能力空间）子系统** 进行形式化验证。
目前的策略是：**高层逻辑严格证明 + 底层内存隔离信任（Refinement 精化模型）**。

## 2. 代码现状 (哪些证了，哪些没证)
目前工具链 `tools/check-cspace-build-and-verify.sh` 能稳定跑通 (211 验证通过，0 错误)。

**✅ 已经严格验证的 (Verified Logic)**:
- **CSpace 的抽象模型定义**：完全对齐了 l4v 的数学模型。
- **查询与权限校验 API**：如 `same_region_as`、`is_final_cap`、`derive_cap`、`ensure_no_children` 均已提供原生 Verus 证明，且消除了历史散落的 `assume`。
- **精化桥接层**：建立了从具体实现到抽象理论的映射（虽然仍带有少量没收口的小工具）。

**⚠️ 隔离为 TCB (可信基) 不做证明的**:
- **侵入式树状修改（Mutators）**：`cte_insert` / `cte_move` 族。目前只在接口上定义了它们“应该做什么（合约）”，但内部指针腾挪由 `external_body` 信任执行。
- **C/Rust 结构体位域和底层物理地址映射**。
